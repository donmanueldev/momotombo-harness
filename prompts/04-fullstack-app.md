# Fullstack App

Use this when the work spans frontend, backend, and data layers in one app.

Goal:
- <describe the feature or app change>

Instructions:
1. Start with `workflow` and `planner`.
2. Split the work into vertical slices that can ship independently.
3. Use `web` for UI, `backend` for API logic, and `data` for schema or persistence.
4. Use `reviewer` after the slices are implemented.
5. Prefer a narrow first slice that proves the end-to-end path.

Output:
- slices
- dependencies
- tests
- verification
