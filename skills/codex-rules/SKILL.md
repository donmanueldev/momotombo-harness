# Codex Rules

Use this when editing `AGENTS.md`, repository guardrails, or other operating rules for Codex.

## Rules

- Make instructions concise and actionable.
- Keep them aligned with the repo's actual behavior.
- Prefer operational guidance over long explanations.
- Preserve existing user decisions unless the user explicitly asks to replace them.
- Remove stale references to old assistants or workflows.
- Update docs when the rules change in a way that affects daily use.
