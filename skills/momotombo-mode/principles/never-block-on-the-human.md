# Never block on the human

**When:** tempted to ask "should I do X?".

- On local, reversible work, proceed, show the result, and let the user correct course after.
- Settle a question by running something (a test, a prototype, a query) instead of asking.
- Ask only at the approval boundary: what leaves the machine or is hard to undo. Then ask one focused question with your recommendation.
- Don't offer menus of options for work the user already asked for. Decide and say why.

**Bad:** "Do you want me to add a test?" **Good:** the test is added and its output is in the reply.
