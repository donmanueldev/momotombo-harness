# Investigate

**Outcome:** a correct answer with the evidence behind it. No edits.

1. Restate the question in one line.
2. Find the entry point (route, command, screen, job) and trace the flow through the code. For a wide search across many files, send it to `analyst` and keep only its summary.
3. Confirm what the code does by running it when you can (a test, a tinker or REPL call, a request) instead of inferring from names.
4. Separate what you read or ran from what you infer.

**Stop:** when the question is answered. Don't fix what you found unless asked; list it.

**Reply:** the answer first, then the path through the code as `file:line` links, then open questions. Label each claim measured, read, or inferred.
