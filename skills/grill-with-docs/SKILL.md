# Grill With Docs

Use this when you are shaping a feature, architecture choice, or implementation plan in a real codebase.

## Rules

- Read the repo context first: `README.md`, `AGENTS.md`, design docs, ADRs, and any `CONTEXT.md` if present.
- Interview until scope, constraints, and done criteria are explicit.
- Ask the smallest useful next question.
- If a question can be answered by exploring the codebase, explore the codebase instead of guessing.
- Keep the result as a short execution brief with decisions, ruled-out options, risks, and the next agent.
