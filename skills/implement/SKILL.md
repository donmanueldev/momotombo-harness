# Implement

Use this once `/to-spec` or `/to-tickets` is done.

- Implement directly against the agreed seams and interfaces.
- Use `/tdd` where appropriate.
- Run targeted tests and type checks frequently; run full suite once at the end.
- Finish with `/code-review` before commit.

If blockers remain, pause and report them with concrete follow-up items.
