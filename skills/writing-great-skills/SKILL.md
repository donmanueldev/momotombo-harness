# Writing Great Skills

Use this when defining or editing SKILL.md workflows.

- Write concise purpose, scope, and failure modes.
- Use deterministic steps and explicit exit conditions.
- Prefer small nouns, verb-led instructions, and minimal assumptions.
- Validate the skill with realistic edge cases before using it.
