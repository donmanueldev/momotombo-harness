# To Issues

Use this when a PRD or plan needs to become execution work.

## Rules

- Break the work into tracer-bullet vertical slices, not horizontal layers.
- Each issue should be independently actionable, demoable, and small enough for an agent.
- Include title, goal, acceptance criteria, dependencies, and verification for each slice.
- Prefer the smallest slice that can prove the path end to end.
- Present the breakdown for approval before publishing it anywhere.
