# Issue tracker

## Repository tracker

- **Tracker**: GitHub Issues
- **Repository**: `manuelduarte077/agent-config`
- **Primary intake source**: GitHub issues, PRs, and local prompts using the standard intake template.

## PRs as triage source

- External PRs are treated as triage entry points and should be routed through the same intake path as issues.

## Workflow notes

- For bootstrapping and triage-heavy work, use `docs/orchestration-task-requests.md`.
- Track concrete outcomes and decisions through issue labels and task links.
