# 🎯 Native config and permissions

## 💡 Convention

- The app config (`app.json` or `app.config.ts`) and its config plugins are the only source of native config. With Continuous Native Generation, `ios/` and `android/` are generated by `npx expo prebuild`; never edit them by hand.
- Check every config key and plugin option against the Expo docs for the project's SDK version before writing it into a plan or code. Don't write a key from memory.
- Permissions:
  - Ask for a permission only when the user starts the feature that needs it, and handle "denied" with an explanation and a link to Settings.
  - **iOS**: give each permission a purpose string that names the feature. Set it through the library's config plugin option, or `ios.infoPlist` when the library has none.
  - **Android**: libraries add their own permissions. Use `android.permissions` only for one a library doesn't add, and remove unused ones with `android.blockedPermissions` (full name, such as `android.permission.RECORD_AUDIO`).
- Localization:
  - Read the locale with the `useLocales()` hook from `expo-localization`, not a one-time `getLocales()`. Android doesn't restart the app when the language changes.
  - Declare the supported languages with `supportedLocales` on the `expo-localization` plugin, so users can pick the app language in system settings.
  - Translate the app name and permission strings with `locales`, plus `ios.infoPlist.CFBundleAllowMixedLocalizations: true`.
  - Format dates, numbers, and money with `Intl`.
- Any change to native config needs a new build. It can't ship through EAS Update.

## 🏆 Benefits

- Store reviews don't reject the build for vague purpose strings or permissions the app never uses.
- Native folders can be regenerated at any time, so SDK upgrades don't fight hand edits.
- Users get the app, its name, and its system dialogs in their own language.

## 👀 Examples

### ✅ Good: plugin options, specific purpose strings, blocked extras, localized metadata

```json
{
  "expo": {
    "ios": { "infoPlist": { "CFBundleAllowMixedLocalizations": true } },
    "android": { "blockedPermissions": ["android.permission.RECORD_AUDIO"] },
    "locales": { "es": "./locales/es.json" },
    "plugins": [
      ["expo-camera", { "cameraPermission": "Scan the QR code on a receipt to add it to your expenses." }],
      ["expo-localization", { "supportedLocales": { "ios": ["en", "es"], "android": ["en", "es"] } }]
    ]
  }
}
```

### ❌ Bad: generic strings, hand-edited native files, Android permissions nothing uses

```json
{
  "expo": {
    "ios": { "infoPlist": { "NSCameraUsageDescription": "This app needs the camera." } },
    "android": { "permissions": ["CAMERA", "READ_EXTERNAL_STORAGE", "ACCESS_FINE_LOCATION"] }
  }
}
```

Here `ios/MyApp/Info.plist` was also edited by hand, and the next `prebuild` wipes that edit.
